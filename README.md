# Coffee Shop SQL Analysis

## Project Overview

This project focuses on analyzing coffee shop data using SQL to extract meaningful insights and understand business performance.

## Project Objectives

- Explore and analyze coffee shop data.
- Write SQL queries to retrieve relevant information.
- Perform data analysis using SQL.
- Generate meaningful insights from the available dataset.

## Tools Used

- SQL
- PostgreSQL

## SQL Concepts Used

- SELECT statements
- WHERE conditions
- GROUP BY
- ORDER BY
- Aggregate Functions
- JOINs
- Subqueries
- Common Table Expressions (CTEs)

## Project Files

- **Coffee_Shop_Analysis.sql** – Contains the SQL queries used in the project.
- **Coffee_Shop_Project_Report.pptx**– Contains the project documentation and analysis.

## Key Learnings

- SQL query writing
- Data retrieval and filtering
- Data analysis
- Generating business insights
